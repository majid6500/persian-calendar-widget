# ویجت تقویم شمسی

ویجت رومیزی ویندوز ۱۱ با تقویم جلالی، ساعت، تعطیلات رسمی و مناسبت‌ها،
به‌همراه هوای فعلی و پیش‌بینی چندروزه. ویجت کوچک همیشه روی دسکتاپ می‌ماند؛
با کلیک روی آن تقویم ماهانه باز می‌شود و از منوی سینی یا منوی زمینه می‌توان آن
را مدیریت کرد.

- رابط کاملاً فارسی و راست‌به‌چپ با اعداد فارسی
- تم شیشه‌ای تیره با رنگ تأکید فیروزه‌ای، فونت وزیرمتن (همراه بسته) و
  پشتیبانی از نمایشگرهای High-DPI
- تقویم و تعطیلات کاملاً آفلاین؛ هوا فقط پس از انتخاب دستی شهر و در صورت
  دسترسی به اینترنت دریافت می‌شود
- تنظیمات هر کاربر در `%APPDATA%`، جدا از پوشهٔ برنامه
- نسخهٔ قابل حمل (onedir) با PyInstaller

## نگاه سریع

| بخش | وضعیت |
|---|---|
| ویجت رومیزی | تاریخ شمسی، روز هفته، ساعت با ثانیه، تاریخ میلادی، نوار پیشرفت روز |
| هوا | شرایط فعلی، رطوبت، باد، بیشینه/کمینه و پیش‌بینی ۵ روزه |
| تقویم ماهانه | شبکهٔ ۶×۷، شروع از شنبه، تعطیلات و مناسبت‌ها، پنل جزئیات |
| پیمایش | ماه قبل/بعد، دکمهٔ «امروز»، کلیدهای PageUp/PageDown/Home |
| سینی سیستم | نمایش/مخفی کردن ویجت، تقویم، تنظیمات، خروج |
| تک‌نمونه‌ای | اجرای دوباره، نمونهٔ موجود را فعال می‌کند |
| تنظیمات | شفافیت، اندازه، رنگ تأکید، تاریخ میلادی، شهر هوا، واحدها، همیشه در جلو، اجرای خودکار |
| ذخیره‌سازی | `%APPDATA%\PersianCalendarWidget\settings.ini` |
| دادهٔ تعطیلات | ۱۴۰۲–۱۴۲۶، همراه برنامه، بدون به‌روزرسانی آنلاین |
| دادهٔ هوا | Open-Meteo، اختیاری، با حافظهٔ محلی و به‌روزرسانی حدوداً هر ۱۵ دقیقه |

## پیش‌نیازها

- ویندوز ۱۱ (تست‌شده روی Windows 11 Pro build 26300)
- Python 3.13.15
- PySide6 6.12.0
- jdatetime 6.1.1

## نصب و اجرا از سورس

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

اگر محیط مجازی از قبل ساخته شده است:

```powershell
.\.venv\Scripts\python.exe main.py
```

نسخهٔ بسته‌بندی‌شده بدون پنجرهٔ کنسول اجرا می‌شود؛ اجرای سورس با
`python.exe` پنجرهٔ کنسول دارد (برای اجرای بی‌کنسول از `pythonw.exe` استفاده
کنید). برای بستن کامل، از منوی سینی یا منوی زمینهٔ ویجت گزینهٔ «خروج» را
انتخاب کنید. بستن پنجرهٔ تقویم یا مخفی کردن ویجت، برنامه را نمی‌بندد.

## استفاده

- **کلیک روی ویجت**: باز شدن تقویم ماهانه.
- **کشیدن ویجت**: جابه‌جایی؛ موقعیت پس از رها کردن ذخیره می‌شود.
- **منوی زمینهٔ ویجت**: تقویم، تنظیمات، به‌روزرسانی هوا، منبع دادهٔ هوا،
  مخفی کردن، خروج.
- **تقویم**: انتخاب روز، پیمایش ماه، بازگشت به امروز، مشاهدهٔ تعطیلات و
  مناسبت‌های روز. روز جاری و روز انتخاب‌شده ظاهر متفاوتی دارند.
- **هوا**: پس از انتخاب شهر در تنظیمات، شرایط فعلی و پیش‌بینی ۵ روزه نمایش
  داده می‌شود. کلیک روی «Open-Meteo» در پایین ویجت، صفحهٔ منبع داده را باز
  می‌کند.
- **تنظیمات**: پیش‌نمایش زندهٔ شفافیت، اندازه و رنگ؛ دکمهٔ «ذخیره» تغییرات را
  پایدار می‌کند و «انصراف» به مقادیر ذخیره‌شده برمی‌گردد. «بازنشانی» مقادیر
  پیش‌فرض را برمی‌گرداند، اما شهر هوا و واحدهای انتخاب‌شده را نگه می‌دارد.

### تنظیمات

| تنظیم | بازه/مقدار |
|---|---|
| شفافیت ویجت | ۶۰٪ تا ۱۰۰٪ |
| اندازهٔ ویجت | ۸۰٪ تا ۱۳۰٪ |
| رنگ تأکید | ۷ رنگ آماده + انتخاب رنگ دلخواه |
| نمایش تاریخ میلادی | روشن/خاموش |
| شهر هوا | جستجوی دستی نام شهر؛ بدون ردیابی خودکار موقعیت |
| واحد دما | سلسیوس (°C) یا فارنهایت (°F) |
| واحد باد | کیلومتر بر ساعت، متر بر ثانیه، مایل بر ساعت یا گره |
| همیشه در جلوی پنجره‌ها | روشن/خاموش |
| اجرای خودکار هنگام ورود به ویندوز | روشن/خاموش |

تنظیمات در فایل INI زیر ذخیره می‌شوند:

```text
%APPDATA%\PersianCalendarWidget\settings.ini
```

برای اجرای قابل حمل با تنظیمات جدا، می‌توانید متغیر محیطی
`PCW_CONFIG_DIR` یا گزینهٔ `--config-dir` را تنظیم کنید. فایل خطا نیز در همان
پوشه با نام `error.log` ذخیره می‌شود.

### هوا

- منبع: [Open-Meteo](https://open-meteo.com/) با مجوز
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). نیازی به کلید
  API نیست.
- جستجوی شهر با سرویس Geocoding همین سرویس انجام می‌شود و شهر فقط به‌صورت
  دستی انتخاب می‌شود؛ برنامه موقعیت مکانی دستگاه را ردیابی یا حدس نمی‌زند.
- شرایط فعلی، رطوبت، سرعت باد، بیشینه/کمینهٔ امروز و پیش‌بینی ۵ روزه نمایش
  داده می‌شود. واحدهای پیش‌فرض سلسیوس و کیلومتر بر ساعت هستند.
- درخواست‌ها ناهمگام (غیرمسدودکننده)، دارای timeout، بدون درخواست هم‌زمان
  تکراری و با به‌روزرسانی خودکار حدوداً هر ۱۵ دقیقه اجرا می‌شوند. از منوی
  زمینهٔ ویجت نیز می‌توان دستی به‌روزرسانی کرد.
- آخرین پاسخ موفق در فایل زیر ذخیره می‌شود و در حالت آفلاین یا خطای شبکه،
  همان دادهٔ ذخیره‌شده با برچسب «ذخیره‌شده» نمایش داده می‌شود:

  ```text
  %APPDATA%\PersianCalendarWidget\weather-cache.json
  ```

- اگر شهری انتخاب نشده باشد، هیچ درخواست شبکه‌ای ارسال نمی‌شود و ویجت فقط
  راهنمای انتخاب شهر را نشان می‌دهد.
- برای حفظ حریم خصوصی، فقط مختصات شهر انتخاب‌شده به Open-Meteo ارسال می‌شود؛
  هیچ شناسهٔ کاربری یا موقعیت خودکار ارسال نمی‌گردد.

### اجرای خودکار در ویندوز

فقط یک مقدار در کلید زیر ساخته یا حذف می‌شود و به دسترسی مدیر نیاز ندارد:

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
نام مقدار: PersianCalendarWidget
```

با خاموش کردن گزینه در تنظیمات، همان مقدار حذف می‌شود. اگر برنامه از مسیر
دیگری اجرا شود، فرمان ثبت‌شده در اجرای بعدی به‌طور خودکار به‌روزرسانی
می‌شود.

## دادهٔ تعطیلات

- دادهٔ تعطیلات در زمان اجرا از اینترنت دریافت یا حدس زده نمی‌شود؛ فقط هوا
  (در صورت انتخاب شهر) از شبکه خوانده می‌شود.

## آزمون‌ها

```powershell
pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

پوشش آزمون‌ها:

- ریاضیات تاریخ جلالی، سال کبیسه، طول ماه‌ها، مرز سال و شبکهٔ ۶×۷
- اعداد، نام ماه‌ها و روزها، تاریخ بلند، بازهٔ میلادی و ساعت
- بارگذاری دادهٔ تعطیلات، تاریخ‌های شناخته‌شده، مناسبت‌ها، دادهٔ خراب و
  فایل گم‌شده
- اعتبارسنجی تنظیمات، ذخیره/بازخوانی INI و بازنشانی
- تنظیمات هوا: ذخیرهٔ شهر و واحدها، اعتبارسنجی مختصات و حفظ شهر در بازنشانی
- پارس پاسخ Open-Meteo، ساخت URL، توصیف‌های WMO و کش JSON
- ماشین حالت سرویس هوا: کش تازه، موفقیت، خطای شبکه، حالت کهنه و لغو
- جستجوی شهر در تنظیمات با پروتکل ساختگی و بدون شبکه
- چیدمان تقویم، انتخاب روز، پیمایش ماه، «امروز» و جزئیات تعطیلات
- ویجت، کشیدن، کلیک، موقعیت، شفافیت، اندازه و حالت‌های هوا
- پنجرهٔ تنظیمات، پیش‌نمایش، ذخیره/انصراف و رنگ دلخواه
- ثبت/حذف کلید اجرای خودکار ویندوز با مقدار آزمایشی یکتا
- تک‌نمونه‌ای با سوکت محلی واقعی
- راه‌اندازی و خاموشی کامل برنامه در یک فرایند جداگانه با `--smoke-test`

آزمون‌های رابط کاربری روی پلتفرم `offscreen` اجرا می‌شوند و تنظیمات واقعی
کاربر را تغییر نمی‌دهند.

## ساخت نسخهٔ قابل حمل

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

این اسکریپت:

1. تست‌ها را اجرا می‌کند (با `-SkipTests` می‌توان رد کرد).
2. با PyInstaller و فایل `packaging/PersianCalendarWidget.spec` ساخت onedir
   انجام می‌دهد.
3. فایل اجرایی بسته‌بندی‌شده را با `--smoke-test` آزمایش می‌کند.
4. گزارش JSON را در `%TEMP%\pcw-packaged-smoke.json` می‌نویسد.

خروجی:

```text
dist\PersianCalendarWidget\
├── PersianCalendarWidget.exe
└── _internal\...
```

اجرا:

```powershell
.\dist\PersianCalendarWidget\PersianCalendarWidget.exe
```

این نسخه قابل حمل است؛ می‌توان پوشه را جابه‌جا کرد. تنظیمات همچنان در پروفایل
کاربر و خارج از پوشهٔ برنامه ذخیره می‌شود. حذف برنامه با پاک کردن پوشه انجام
می‌شود؛ برای پاک کردن کامل، مقدار اجرای خودکار را در تنظیمات خاموش کنید و
در صورت تمایل `%APPDATA%\PersianCalendarWidget` را حذف کنید.

### گزینه‌های تشخیصی

```powershell
# آزمون دود و خروج
.\dist\PersianCalendarWidget\PersianCalendarWidget.exe --smoke-test

# نوشتن گزارش JSON
... --smoke-test --smoke-report "$env:TEMP\pcw-smoke.json"

# ذخیرهٔ تصویر ویجت/تقویم/تنظیمات (ابزار توسعه)
... --screenshot-dir "$env:TEMP\pcw-shots"

# نمایش نسخه
... --version

# اجرا با تنظیمات موقت
... --config-dir "$env:TEMP\pcw-config"
```

در حالت عادی فقط یک نمونه اجرا می‌شود. `--no-single-instance` فقط برای
عیب‌یابی است.

## محدودیت‌ها و موارد بررسی‌نشده

- دادهٔ رسمی فقط ۱۴۰۲–۱۴۲۶ را پوشش می‌دهد؛ خارج از آن داده‌ای نمایش داده
  نمی‌شود.
- مجموعهٔ مناسبت‌ها کامل نیست و به‌روزرسانی آنلاین ندارد.
- هوا به دسترس‌پذیری Open-Meteo و اینترنت وابسته است؛ در حالت آفلاین آخرین
  دادهٔ ذخیره‌شده نمایش داده می‌شود و ممکن است کهنه باشد. هشدارهای شدید
  جوی، آلودگی هوا و رادار در این نسخه وجود ندارد.
- شهر هوا را باید دستی انتخاب کرد؛ مکان‌یابی خودکار و تشخیص شهر از IP
  عمداً پیاده‌سازی نشده است.
- «اجرای خودکار» با ثبت/حذف مقدار رجیستری آزموده شده، اما ورود واقعی به
  ویندوز پس از ری‌استارت به‌صورت دستی بررسی نشده است.
- تعامل با منوی سینی روی Taskbar واقعی به‌صورت دستی آزموده نشده است؛
  مسیرهای کد و نبود سینی به‌صورت کنترل‌شده مدیریت می‌شوند.
- چیدمان چند-مانیتوری بررسی نشده است؛ الگوریتم انتخاب صفحه و محدودسازی
  موقعیت پیاده‌سازی شده است.
- «همیشه در جلو» با بررسی سبک توسعه‌یافتهٔ ویندوز (`WS_EX_TOPMOST`) تأیید
  شده، اما روی همهٔ انواع پنجره‌های سایر برنامه‌ها آزمون بصری نشده است.
