# دادهٔ تعطیلات و مناسبت‌ها

این پوشه دادهٔ آفلاین تقویم را نگه می‌دارد. برنامه در زمان اجرا به اینترنت
دسترسی ندارد و همهٔ رویدادها را از `holidays.json` می‌خواند.

## پوشش

- سال‌های شمسی: **۱۴۰۲ تا ۱۴۲۶** (۲۱ مارس ۲۰۲۳ تا ۱۹ مارس ۲۰۴۸)
- تعطیلات رسمی: **۶۸۸ رکورد** روی **۶۷۰ روز** (بعضی روزها بیش از یک رویداد رسمی دارند)، با **۲۴ شناسهٔ** متمایز
  - ۴۳۸ رکورد مذهبی و ۲۵۰ رکورد ملی
- مناسبت‌ها: **۵۷ رکورد** روی **۵۴ روز/ماه** (بعضی روزها دو مناسبت دارند)
  - ۲۳ فرهنگی، ۱۹ ملی، ۸ تاریخی و ۷ آیین کهن
- تاریخ تولید داده: ۲۷ اکتبر ۲۰۲۶ (۱۴۰۵/۰۸/۰۵)

خارج از این بازه، تقویم و تبدیل تاریخ همچنان کار می‌کند، اما در پنل جزئیات
پیام «اطلاعات تعطیلات برای این سال در نسخهٔ فعلی موجود نیست» نمایش داده
می‌شود. هیچ تاریخ تعطیلی برای خارج از بازه ساختگی تولید نمی‌شود.

## تفاوت «تعطیل رسمی» و «مناسبت»

- **تعطیل رسمی**: روز تعطیل رسمی ایران؛ در رابط کاربری با رنگ قرمز و نشان
  «تعطیل رسمی» مشخص می‌شود. این رکوردها تاریخ‌دار و سال‌به‌سال هستند، چون
  تعطیلات قمری در تقویم شمسی جابه‌جا می‌شوند.
- **مناسبت**: روز بزرگداشت یا یادبود است و به‌تنهایی باعث تعطیلی نمی‌شود؛ با
  نشان «مناسبت» و نقطهٔ رنگی نمایش داده می‌شود. این‌ها تاریخ ثابت شمسی دارند
  و هر سال تکرار می‌شوند.
- **جمعه**: تعطیل هفتگی است، نه تعطیل رسمی؛ در رابط کاربری قرمز نمایش داده
  می‌شود، اما در فهرست تعطیلات رسمی داده نیست.

## قالب فایل

```json
{
  "schema_version": 1,
  "generated_at": "2026-10-27",
  "coverage": { "min_year": 1402, "max_year": 1426 },
  "sources": [ ... ],
  "holidays": [
    {
      "date": "1402-01-01",
      "id": "nowruz",
      "title": "نوروز",
      "category": "national",
      "description": "آغاز سال نو و جشن باستانی نوروز.",
      "source": "jalali-js-holidays"
    }
  ],
  "occasions": [
    {
      "month": 1,
      "day": 6,
      "id": "zarathustra-birth",
      "title": "زادروز زرتشت پیامبر",
      "category": "ancient",
      "description": "گرامیداشت زادروز زرتشت، پیامبر ایران باستان.",
      "source": "persian-holidays"
    }
  ]
}
```

- `date` در `holidays` تاریخ شمسی به شکل `YYYY-MM-DD` است.
- `month` و `day` در `occasions` تاریخ ثابت شمسی است و هر سال تکرار می‌شود.
- `category` یکی از `national`، `religious`، `cultural`، `historical`،
  `ancient` یا `civic` است.
- `official` در کد از روی قرار گرفتن در فهرست `holidays` تعیین می‌شود؛
  مناسبت‌ها همیشه غیررسمی‌اند.

## بازتولید داده

فایل خام منبع در `tools/upstream/jalali_js_holidays_0.4.2.json` نگهداری
می‌شود. برای بازسازی:

```powershell
.\.venv\Scripts\python.exe tools\generate_holidays.py
.\.venv\Scripts\python.exe -m pytest tests\test_holidays.py -q
```

اسکریپت `tools/generate_holidays.py` عنوان‌ها، دسته‌ها و توضیح‌های تعطیلات
را از نگاشت `HOLIDAY_META` و مناسبت‌ها را از فهرست `OCCASIONS` می‌سازد.
هیچ تاریخ رسمی به‌صورت دستی حدس زده نمی‌شود؛ تاریخ‌ها فقط از دادهٔ منبع
می‌آیند.

## بررسی‌های نمونه

- ۱۴۰۳/۰۱/۰۱: نوروز
- ۱۴۰۳/۰۱/۱۳: روز طبیعت + شهادت امام علی (ع)
- ۱۴۰۴/۰۱/۰۲: نوروز + شهادت امام علی (ع)
- ۱۴۰۵/۰۱/۰۱: نوروز + عید فطر
- ۱۴۰۵/۰۲/۲۵: بزرگداشت فردوسی + روز پاسداشت زبان فارسی (مناسبت، نه تعطیل)

## محدودیت‌ها

- دادهٔ رسمی فقط ۱۴۰۲–۱۴۲۶ را پوشش می‌دهد.
- تاریخ‌های قمری به دادهٔ منبع وابسته‌اند و ممکن است در نسخه‌های آیندهٔ منبع
  اصلاح شوند.
- مجموعهٔ مناسبت‌ها کامل نیست؛ گزیده‌ای از مناسبت‌های شناخته‌شده است.
- برنامه به‌صورت خودکار داده را به‌روزرسانی نمی‌کند؛ برای به‌روزرسانی باید
  فایل داده یا ابزار تولید آن را جایگزین و تست‌ها را اجرا کرد.
